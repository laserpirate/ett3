# ett3

Course pages for ett3 (Fall 2026), served on GitHub Pages at https://laserpirate.github.io/ett3/

- `a3-groundtruth/`: Assignment 3, Ground Truth, Alewife Brook Conservation Area. Share page for the group packet.
- The packet zip is a Release asset (tag `a3-groundtruth-packet-v01`), not a repo file.
- Rebuild: `python _build/build_a3_v01.py` (copies the newest packet from the course lane, writes the pages, runs the gate), then `--release`, `--check-live`, `--shots`.
- Open by link, not indexed: `robots.txt` disallows all and every page carries a noindex meta.
- Fonts: Public Sans (SIL Open Font License), self-hosted as woff2 in `assets/fonts/`.

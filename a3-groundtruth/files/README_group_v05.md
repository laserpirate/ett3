## Which file to open
- **Review:** `ett3-A3_packet_review_v05.pdf` (every open slot boxed and numbered, list at the end). `ett3-A3_packet_v05.pdf` is the clean print set. `png/` has one PNG per page.
- **Draw:** `ai/ett3-A3_<sheet>_vNN.ai`, one per drawing sheet, or `ai/ett3-A3_packet_v08.ai` (12 artboards). Rasters are linked from `links/`.
- **Lay out:** `indd/ett3-A3_packet_v08.indd` (or `.idml`). Drawing pages place the sheet's `.ai`; pages 10 and 11 are native InDesign: drop photos into the frames on layer `photos`, type on layer `group-edit`.

## Fonts
Public Sans (OFL). Mac: double-click each OTF in `fonts/` > Install. PC: right-click > Install.

## Editing rules
- Work on a copy, add your initials: `..._v02_MK.ai`. Never edit `underlay` or `plan` (locked). Draw on `annot-field`.
- Species: edit `01_src/ett3-A3_species_v01.csv` (send to Marko) when you confirm an ID.
